# wb-switch 版本介绍

> WorkBuddy 模型源切换器 —— 把不同网关配置存成独立的「源」，图形界面一键切换，不用再手改 `~/.workbuddy/models.json`。
> 当前版本：**v2.2.0**

---

## 一句话看懂这次更新

**v2.2.0 把 wb-switch 从「切换工具」升级成「模型能力工作台」**：新增图片模型与模型组的可视化管理，把 SenseNova U1.5 生图/改图能力通过标准 MCP 暴露给 WorkBuddy 等 agent；同时 CLI 随应用打包、装完即用，并对「切换」这件事做了从信息分层到交互反馈的完整重做。

---

## v2.2.0 更新详情

### 1. 图片模型：SenseNova U1.5 生图 / 改图（v2.1.0 引入，v2.2.0 补齐 GUI + MCP）

- **接口对接**：`POST /v1/images/generations|edits`，Bearer 鉴权复用现有源密钥；请求/响应与 OpenAI Images 同构，扩展 `watermark` / `prompt_extend` / `output_format`。支持 **U1.5 Lite** 与 **U1.5 Fast**。
- **网关适配**：新增 `kind=image` 路由，网关透传 `/v1/images/*` 并复用 v2 调度（熔断/失败分类/预算）；提供 chat↔images 双向适配，普通对话里也能触发生图。图片属长任务，首字节超时放宽到 150s、预算 ≥180s。
- **三层调用入口**：
  - GUI「图片」页（标记图片模型 → 配路由 → 试一张，含图片预览）
  - CLI `wb-switch image mark/route/gen/edit`
  - 标准 MCP：`generate_image` / `edit_image` / `list_models`，任何支持 MCP 的 agent 可直接调用
- **多源 fallback**：图片路由支持多个源串联，遇到配额 429 自动冷却并切下一个源。

### 2. CLI 随应用打包，安装即用（免仓库、免绝对路径）

- 安装包内嵌一份 **esbuild 单文件 CLI**（零依赖，约 224 KB），app 启动时自动装进 PATH。
- 配套 `wb-switch-mcp` 启动器自行定位 node，解决 MCP 子进程不继承终端 PATH 导致的「连不上」。
- 结果：**下载 DMG 安装后，无需仓库代码即可用** `wb-switch` 命令和 MCP 服务；「图片」页提供 MCP 状态自检与「一键写入/修复配置」。

### 3. 模型组（Combo）

- 把多个源的模型聚合成一个「独立源」，支持「切换」（整体覆盖）与「追加」（并进现有配置不覆盖）两种模式。
- GUI「模型组」页提供可视化新建、成员管理（三级联动下拉选择 源/模型）。

### 4. 切换体验重做

- **信息分层**：主区顶部新增「当前生效」卡片，展示磁盘 `models.json` 的真实状态（生效源、一致性、模型数、上次切换时间，绿/黄/红三态）；下方源详情明确标注「源库快照」，两者不再混淆。
- **完整反馈**：切换中按钮置灰 + 列表项转圈；成功后自动选中目标并刷新生效卡；失败时内联错误条 + 重试按钮（配置自动回滚）；空源、解析失败、磁盘被改动等状态都有明确文案。
- **状态全界面同步**：侧栏「当前生效」卡、列表项「生效中」标签、主区生效卡三处一致；生效源变化时列表项自动滚入视区；5 秒轮询 + 窗口聚焦刷新，CLI/托盘等外部切换 5 秒内 GUI 自动跟上。
- **布局优化**：页签从侧栏底部（原 4+2 折行）移到主区域顶部横向导航条，交互更符合「先选页、再看内容」的习惯。

### 5. 网关调度核心（v2.0.0 引入）

- 失败分类：transient / rate / quota / auth / client，据此决定重试或熔断。
- 熔断状态机：closed → open → half-open → cooldown；配额 429 零重试 + 30 分钟冷却。
- 请求预算 `budgetMs`（支持热加载）、首字节超时、并发信号量（≤6）、SSE 背压、priority / round-robin 调度。
- 连通性测试与健康面板，切换前可探活。

## 安装与升级

| 平台 | 产物 | 说明 |
| --- | --- | --- |
| macOS | `dist-app/wb-switch-2.2.0.dmg` | 拖拽到「应用程序」；无签名需右键「打开」 |
| Windows | `wb-switch-Setup-2.2.0.exe` / portable | 安装向导或免安装版 |
| Linux | `wb-switch-2.2.0.AppImage` / deb | 赋予执行权限后运行 |

**升级**：直接覆盖安装即可，源配置、备份、路由等数据都存在用户配置目录，不会丢失。安装后首次启动会自动更新内嵌 CLI 与 MCP 启动器。

---

## 验证要点（升级后自检）

1. **切换闭环**：选一个源点「切换到此源」→ 生效卡变绿、「生效中」标签跟随 → 重启 WorkBuddy 或新开对话生效。
2. **状态同步**：在终端跑 `wb-switch use <源名>`，5 秒内 GUI 生效状态自动跟上。
3. **图片能力**：「图片」页确认路由存在 → 标记图片模型 → 试一张；MCP 卡片显示「配置正常」后，agent 侧可看到 `generate_image` 等三个工具。
4. **MCP 自检**：若显示「MCP 未就绪」，点「写入 / 修复配置」后重启 WorkBuddy。
5. **安全兜底**：切换失败时磁盘配置自动回滚，错误条提供重试入口。
